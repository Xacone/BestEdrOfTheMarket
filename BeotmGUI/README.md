# BEOTM GUI

The official GUI for BEOTM, available in your favorite browser.

Visualize and inspect easily the events detected by BEOTM.

It is a [Svelte](https://svelte.dev/docs/svelte) project.

Dependencies are managed with [pNPM](https://pnpm.io/).

- **Install dependencies** with `pnpm install`
- **Open a development server** with `pnpm dev`
- **Verify the validity of the code** with `pnpm check`
- **Format the code** with `pnpm format`
- **Build** the production files with `pnpm build`
- **Preview** the production result with `pnpm preview`
